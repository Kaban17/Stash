# СтажТрек

Парсер IT-стажировок и Junior / New Grad вакансий (РФ и зарубежные компании) с таблицей дедлайнов, календарем сроков, справочником работодателей и трекером откликов.

## Основные возможности

- **Живой серверный парсинг вакансий** — сбор открытых стажировок и Junior / New Grad позиций (с фокусом на Backend и ML/Data) из публичных API и ATS-досок.
- **Таблица дедлайнов с прямыми ссылками** — отображение компании, грейда, направления, города, формата работы, срочности дедлайна, оплаты и отдельной колонки с прямой кликабельной ссылкой на вакансию и копированием в 1 клик.
- **Фильтрация и сортировка**:
  - быстрый фильтр **«Бек + ML»**, фильтры по рынку (`РФ` / `Зарубеж`), грейду (`Стажёр` / `Junior`), направлению, городу, формату работы (`Удалённо`, `Гибрид`, `Офис`);
  - сортировка по дедлайну, формату работы, городу, направлению, оплате, компании и статусу;
  - быстрые срезы (`Все`, `Горящие`, `К подаче`, `В процессе`, `Избранные`);
  - чекбокс **«Скрыть просроченные (> 7 дн.)»**, автоматически скрывающий вакансии с дедлайном старше 7 дней и сохраняющий состояние в `localStorage`.
- **Трекер откликов** — статусы (`Не подано`, `В планах`, `Откликнулся`, `Тестовое`, `Собеседование`, `Оффер`, `Отказ`), избранное, заметки и редактирование дедлайна в боковой карточке; при повторном парсинге пользовательские данные сохраняются благодаря дедупликации.
- **Календарь сроков** — помесячное отображение дедлайнов и выгрузка напоминаний в календарь.
- **База компаний (129 работодателей)** — 71 IT-компания РФ и 58 зарубежных компаний с прямыми ссылками на карьерные порталы и кнопкой точечного поиска открытых вакансий по выбранной компании.
- **Импорт вручную, по URL или из HTML/текста** — разбор JSON-LD (`JobPosting`), мета-тегов и русскоязычных формулировок дедлайнов (*«до 25 ноября 2026»*, *«дедлайн: 05.12.2026»* и т.д.).
- **Экспорт данных** — выгрузка отфильтрованной таблицы в `.csv` (UTF-8 BOM для Excel / Google Таблиц) и дедлайнов в `.ics` (с напоминаниями для Google Calendar / Apple Calendar).

## Источники парсинга

| Источник | Покрытие | Механизм |
| --- | --- | --- |
| **Хабр Карьера API (Intern)** | РФ, стажировки (`qid=1`) | Публичный JSON API + HTML fallback |
| **Хабр Карьера API (Junior Backend & ML)** | РФ, Junior (`qid=3`) | Публичный JSON API по Backend / Python / ML |
| **HeadHunter API** | РФ (топ-12 работодателей и общий поиск) | `api.hh.ru/vacancies` (с прямым разбором `hh.ru/vacancy/<id>`) |
| **Карьерные порталы РФ** | Яндекс, Т-Банк, VK | HTML / JSON-LD парсинг |
| **Greenhouse ATS API** | Stripe, Databricks, Anthropic, Cloudflare, Scale AI, Coinbase, Airbnb, Duolingo, MongoDB, Adyen и др. | `boards-api.greenhouse.io` |
| **Ashby ATS API** | OpenAI, Perplexity, Cohere, Notion, Snowflake, Ramp, Harvey и др. | `api.ashbyhq.com` |
| **Lever ATS API** | Palantir, Zoox | `api.lever.co` |
| **Arbeitnow API** | Европа (Working Student, Intern, Junior) | `arbeitnow.com/api/job-board-api` |

> Примечание: доступность отдельных внешних ресурсов (например, `api.hh.ru` или некоторых корпоративных порталов) может зависеть от IP-адреса и сетевых ограничений среды запуска. В качестве резервного варианта поддерживается импорт произвольного URL, вставка HTML/текста вакансии и ручное добавление.

## Технологический стек

- **Frontend**: React 19, TypeScript, Tailwind CSS v4, Lucide Icons
- **Backend**: Express 4, Cheerio (HTML/JSON-LD парсинг), `tsx`
- **Сборка и тесты**: Vite 8, `tsc --noEmit`, встроенный тест-раннер Node.js (`node:test`)

## Быстрый старт

Требуется **Node.js 20+**.

```bash
# 1. Установка зависимостей
npm install

# 2. Запуск в режиме разработки (Express API + Vite middleware на порту 3000)
npm run dev
```

После запуска приложение будет доступно по адресу: `http://localhost:3000`.

### Полезные команды

```bash
# Сборка клиентского бандла (dist/)
npm run build

# Проверка типов TypeScript
npm run lint

# Запуск юнит-тестов (парсер, дедлайны, фильтры, URL-форматтер, localStorage-настройки)
npx tsx --test src/utils/parser.test.ts src/utils/urlFormat.test.ts

# Продакшн-запуск (после npm run build)
NODE_ENV=production npm start
```

## API-эндпоинты сервера

| Метод и путь | Назначение |
| --- | --- |
| `GET /api/sources` | Список пресетов источников парсинга и ID работодателей HeadHunter |
| `POST /api/parse` | Пакетный запуск выбранных источников (`{ sources: string[], query?: string }`) |
| `POST /api/parse-company` | Точечный поиск Intern / New Grad / Junior вакансий конкретной компании (Greenhouse / Ashby / Lever / Arbeitnow / Хабр Карьера) |
| `POST /api/parse-url` | Загрузка и парсинг одной страницы стажировки по публичному URL (с проверкой безопасности URL) |
| `POST /api/parse-html` | Парсинг вставленного HTML-кода или текста объявления о стажировке |

## Хранение данных в браузере

Приложение не требует внешней БД — пользовательские данные хранятся локально в `localStorage`:

- `stazhtrek_internships_v6` — список отслеживаемых стажировок, статусы откликов, заметки, избранное и пользовательские правки дедлайнов (поддерживается автоматическая миграция со старых версий ключа с сохранением ваших заметок и статусов).
- `stazhtrek_preferences_v1` — пользовательские настройки интерфейса (включая состояние чекбокса `hideExpired` для автоскрытия просроченных более 7 дней назад стажировок).
